## Other changes

- The Markdown guide has a section on emoji. A name between colons has
  always been an emoji; now the guide says so, with examples, where the
  names come from (GitHub's list), and how to keep a name between colons
  as text: a backslash before its first colon, or inline code.

  ```markdown
  Shipped :tada: — the ratio is 1\:100:2, and `:rocket:` stays as written.
  ```

  This shows "Shipped 🎉 — the ratio is 1:100:2, and `:rocket:` stays as
  written."
