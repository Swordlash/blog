## New features

- The help behind the "?" in the bottom right corner has a section on
  emoji, after the one on tables: a name between colons is an emoji, with
  the same examples as the Markdown guide.

  ```markdown
  Shipped :tada:
  ```

  This shows "Shipped 🎉".
