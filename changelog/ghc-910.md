## Other changes

A server deployed with `--system-tools` may now use the machine's GHC 9.10: the
deploy accepts GHC 9.10 or later, where it asked for 9.12 before. haskell-halogen,
the Haskell library the wiki is built on, now supports GHC 9.10 and is tested with
it. GHC 9.14.1 is still the tested version for the wiki itself, so another GHC is
used with a warning. Nothing changes for a build with 9.14.
